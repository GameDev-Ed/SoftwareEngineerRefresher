# Hints

Use this file only when you get stuck.

## BasicFunctions
- `Add` should use the `+` operator.
- `IsAdult` needs a comparison operator.
- `GetLetterGrade` should check the highest score range first.
- `IsValidUsername` can use `.size()`.

## DataStructures
- For `FindLargest`, handle the empty vector first.
- For `CountWord`, loop through every word and compare it to the target.
- For `HasItem`, use `inventory.find(itemName)` before reading the value.

## OOPBasics
- `Deposit` should ignore negative amounts.
- `Withdraw` should check if there is enough balance before subtracting.
- `GetBalance` should return the private member variable.
- `GetDisplayName` can use `std::to_string(level)`.

## FileIO
- For `BuildSaveText`, add `\n` between lines, not after the last line.
- For `SplitLines`, build a temporary string until you reach `\n`.

## Architecture
- `AddTask` should push a new `Task` into the vector.
- `CompleteTask` should search by title.
- Counting functions should loop through `tasks`.
